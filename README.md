# Time Series Forecasting | ETS vs MLP vs Chronos

### Сравнение классических статистических методов, нейронных сетей и предобученных моделей для прогнозирования временных рядов

## О проекте

Проект посвящён исследованию и сравнению различных подходов к прогнозированию модельных временных рядов.

**Цель исследования** — сравнить точность прогнозирования классического экспоненциального сглаживания, полносвязной нейронной сети и предобученной модели временных рядов.

В рамках исследования рассматриваются три подхода:

1. **ETS / Simple Exponential Smoothing** — классический статистический метод.
2. **MLP (Multilayer Perceptron)** — полносвязная нейронная сеть, реализованная на PyTorch.
3. **Amazon Chronos** — предобученная модель для прогнозирования временных рядов.

Для оценки качества используется Mean Squared Error (MSE), усреднённая по реализациям временного ряда, и доверительные интервалы.

## Данные

Исследование проводится на модельных временных рядах, сочетающих кусочно-линейный тренд и броуновское движение.

**Параметры эксперимента:**

- Количество реализаций: 500.
- Длина обучающего участка: 750 наблюдений.
- Длина валидационного участка: 250 наблюдений.
- Длина тестового участка: 250 наблюдений.
- Параметр шума: σ = 1.
- Параметр дополнительной случайной компоненты: σₐ = √0.2.

В исследовании используется прогнозирование на один шаг вперёд.

## Основные этапы

### 1. Подготовка данных

- Загрузка модельных временных рядов.
- Визуализация отдельной реализации.
- Разделение на Train, Validation и Test.
- Вычисление первых разностей временных рядов.
- Стандартизация данных для обучения MLP.

Использование первых разностей позволяет моделировать изменения значений ряда, а не непосредственно его уровень.

### 2. ETS — экспоненциальное сглаживание

В качестве классического статистического подхода используется `SimpleExpSmoothing` из библиотеки Statsmodels.

**Основные этапы:**

- Вычисление первых разностей.
- Оценивание параметра сглаживания.
- Последовательное прогнозирование изменений временного ряда.
- Восстановление прогноза исходного уровня ряда.
- Вычисление MSE для каждой реализации.

### 3. MLP — нейронная сеть на PyTorch

Реализована полносвязная нейронная сеть для прогнозирования следующего значения первых разностей.

**Архитектура:**

- Входное окно: 30 наблюдений.
- Полносвязный слой: 16 нейронов.
- Batch Normalization.
- ReLU.
- Dropout: 0.1.
- Выходной слой: 1 нейрон.

**Параметры обучения:**

- Batch size: 100.
- Epochs: 10.
- Learning rate: 0.001.
- Оптимизатор и функция потерь определены в Jupyter Notebook.

Обучение выполняется отдельно для каждой реализации временного ряда.

### 4. Chronos — предобученная модель

Для сравнения используется предобученная модель `amazon/chronos-t5-tiny`.

**Особенности эксперимента:**

- Используется готовая модель без дополнительного обучения.
- Контекстное окно: 50 наблюдений.
- Прогноз строится на основе первых разностей.
- Применяется одношаговое прогнозирование.
- Качество оценивается на тестовом участке.

Этот подход позволяет сравнить специализированную предобученную модель с классическим статистическим методом и нейронной сетью, обучаемой на данных эксперимента.

## Результаты

### Сравнение моделей

| Модель | Средний MSE | 95% доверительный интервал |
|---|---:|---|
| **ETS** | **1.0529** | **[1.0429; 1.0629]** |
| Chronos | 1.1232 | [1.1133; 1.1330] |
| MLP | 1.1291 | [1.1108; 1.1474] |

Для сравнения в эксперименте используется целевой диапазон MSE:

**[1.0000; 1.2000]**

### Интерпретация результатов

**1. ETS показал наилучший результат**

Средний MSE составил 1.0529 — минимальное значение среди исследованных моделей.

**2. Chronos продемонстрировал конкурентоспособное качество**

Предобученная модель достигла MSE = 1.1232 без дополнительного обучения на исследуемых рядах.

**3. MLP показала близкий к Chronos результат**

Нейронная сеть достигла MSE = 1.1291, однако уступила классическому экспоненциальному сглаживанию.

**4. Все модели попали в заданный диапазон MSE**

Средние ошибки трёх методов находятся в целевом интервале [1.0; 1.2].

В ноутбуке представлены:

Визуализации позволяют оценить не только среднюю точность моделей, но и разброс ошибок между реализациями.

## Основные выводы

1. **Классический метод ETS оказался наиболее точным** для исследуемых модельных временных рядов.
2. Более сложные нейросетевые подходы не обеспечили улучшения качества по сравнению с экспоненциальным сглаживанием.
3. Предобученная модель Chronos показала результат, близкий к MLP, без необходимости дополнительного обучения.
4. Сравнение на множестве реализаций позволяет оценить устойчивость качества прогнозирования.
5. Выбор метода прогнозирования должен учитывать структуру временного ряда, а не только сложность модели.
